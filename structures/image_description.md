# AF3 vs. Boltz-2 seed structure comparison images

All images in this directory prefixed `af3_vs_boltz_seeds_*` show the same
8 structures overlaid on a common protein frame: the **4 representative
(medoid) structures from each of the 4 clusters** generated for each
generative model -- i.e. `af3/superB_pYEEI/md_seeds/cluster1-4_*.cif` (AF3)
and `boltz2/superB_pYEEI/md_seeds/cluster1-4_*.cif` (Boltz-2). These are
the same 8 MD seed structures documented in each tool's own `md_seeds/`
directory; these images compare them directly against each other rather
than within one tool's ensemble.

Color legend (embedded in each PNG): **blue = AF3**, **orange = Boltz-2**.
Each color therefore represents 4 overlaid structures (one per cluster),
not a single structure -- the images intentionally overlay all 4
same-tool cluster representatives on top of each other so within-tool
spread and across-tool spread can be compared in the same view.

- `af3_vs_boltz_seeds_full.png` -- full complex: gray cartoon = shared
  protein fold (SH2 domain, one representative used as the alignment
  reference), peptide backbones + side chains shown as sticks for all 8
  seed structures, pTyr phosphate group shown as spheres.
- `af3_vs_boltz_seeds_peptide_closeup.png` -- same 8 peptides, protein
  hidden, tighter zoom. Shows the pTyr-anchored core (right side)
  overlapping closely across all 8 structures, and the flexible termini
  (left side) splayed apart -- AF3 (blue) diverges mainly at the
  N-terminal end, Boltz-2 (orange) mainly at the C-terminal end.
- `af3_vs_boltz_seeds_ptyr_closeup.png` -- tight close-up on just the
  phosphotyrosine ring + phosphate group. Shows that the pTyr side-chain
  rotamer is not fully converged even within a single tool's own 4
  cluster representatives (not only between AF3 and Boltz-2).
- `af3_vs_boltz_seeds.pse` -- interactive PyMOL session with all 8
  structures loaded and colored as above (object names identify which
  cluster/tool each structure came from).

Generated by `visualize_af3_vs_boltz_seeds.py` (rendering) and
`add_legend.py` (legend overlay). Underlying pairwise RMSD numbers
(within-AF3 / within-Boltz2 / cross-tool, for full peptide, pTyr-anchoring
core, and pTyr side chain) come from `compare_af3_boltz_seeds.py`.
